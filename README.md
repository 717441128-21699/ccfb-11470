# 县级统计报表结构还原工具

浏览器端的统计报表"怪版式"还原工具。**纯本地解析，文件不上传、不出本机**，基于 TypeScript + Vite + SheetJS。

## 它解决什么问题

各县上报的 Excel 报表画法千奇百怪：合并单元格、两三层表头、单位写在角落、小计/合计/备注行夹杂、两张表挤在一个 sheet、指标换说法……
本工具把这些非结构化表格自动还原成统一的标准化长表，并对账各县自报合计与明细加总。

## 五页工作流

| 页面 | 能力 |
| --- | --- |
| ① 导入 | 多选/拖拽 .xlsx，浏览器内 ArrayBuffer 解析，零网络上传 |
| ② 结构识别 | 展示切分后的表块、还原网格、合并对位、表头层级、县名/时期/单位、行类型（明细/小计/合计/备注/空行） |
| ③ 表头映射 | 自动别名+模糊匹配标准指标；未匹配项可手工拖拽式下拉对应，保存为版式指纹模板，下次同版式自动套用 |
| ④ 结果预览 | 标准化长表（县、指标、时期、数值四列 + 单位/溯源），可导出 CSV |
| ⑤ 汇总对账 | 按指标×时期汇总各县明细加总与自报小计，差异自动高亮 |

## 引擎能力（src/engine）

- **网格还原**：合并单元格向下/向右填充，缺失值/千分位/全角字符识别
- **多表切分**：一个 sheet 内按空列（并排）与标题重启（堆叠）切成多张逻辑表
- **多层表头**：两层表头展开、合并格去重、`/` 拼接全名
- **转置表识别**：数据驱动判断时期轴，转置表还原为指标列
- **行分类**：小计/合计（分组标签词）、备注（备注/注/说明前缀）、空行、分组横幅、缺数数据行
- **单位体系**：万元/亿元/千元/元、吨标准煤/万吨标准煤同族换算；混合单位表逐行单位列标注并向下继承
- **时期归一**：`2026年第三季度`、`2026Q3`、`1-3月`、裸`二季度`（兜底年份）统一为 `2026Q3`
- **指标映射**：15 个标准指标、别名库、括号剥离、其中前缀剥离、Levenshtein 相似度
- **版式模板**：FNV 指纹（表头深度+列数+列名+行数），localStorage 持久化，同版式自动套用人工映射
- **汇总对账**：按 分组×时期×来源表 逐县对账，篡改的合计自动高亮

## 语料与准确率

`npm run gen` 生成 200 份确定性（种子随机）县级报表到 `corpus/`，覆盖：

- 垂直表 / 转置表，单期 / 多期
- 单表、并排两表、纵向堆叠 2~3 表、拆两个 sheet
- 合并单元格、两层表头、单位行/标题括号/表头括号、单位列
- 万元/亿元/千元/元/吨标准煤/万吨标准煤换算、混合单位表
- 小计、合计、空行、备注、分组横幅、其中前缀、缺失记号、千分位、文本数字
- 约 12% 文件人为篡改合计用于高亮测试

每份文件附 `.answer.json` 标准答案（逐单元格坐标 + 标准长表 + 排除行）。

## 常用命令

```bash
npm install        # 安装依赖
npm run gen        # 生成 200 份语料 + 标准答案
npm test           # 跑全部测试（含单元格级准确率断言）
npm run dev        # 本地开发服务器
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览构建产物
```

## 测试结果

`npm test` 共 25 个用例，覆盖：

- 单元格级还原准确率（全量 200 份，逐坐标比对指标/时期/县名/行类型/数值）
- 多表切分数量、转置版式、县名/时期/单位提取
- 小计/合计/空行/备注不进明细
- 指标自动映射零未匹配、人工覆盖优先级、指纹稳定性
- 干净文件零误报、篡改文件 100% 高亮且差额正确
- 文本/数值/时期/单位/县名等引擎单元测试

```
tools/        语料生成器（确定性随机）
test/         Vitest 测试
corpus/       生成的 200 份 xlsx + 标准答案 + manifest
```
